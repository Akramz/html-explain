# html-explain plugin

Explain a system as one interactive HTML page with levels you open one at a time. Compare the
Current and Proposed views, mark boxes reviewed, and leave notes on any box; the agent answers
them in place and draws the changes you want, then builds them.

```console
/plugin install html-explain --marketplace Akramz/html-explain
```

Use `/html-explain [focus]`. See https://github.com/Akramz/html-explain.
